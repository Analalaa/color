# Color Muse — 电影截图仿色 LUT 生成设计文档

## 1. 目标

用户上传一张电影截图，系统在零点几秒内生成一个专属 3D LUT（.CUBE 格式）。将该 LUT 应用到用户自己的照片上，即可获得"同款电影色调"。

## 2. 方案概述

采用**分阶段实现**：

- **阶段 1（MVP）**：纯前端统计驱动 LUT 生成，无需后端，验证产品价值
- **阶段 2（增强）**：后端神经网络编码器（Neural Preset 路径），提升效果

## 3. 技术架构

### 3.1 阶段 1：统计 LUT 生成器（纯前端 JS）

```
电影截图（风格参考图）
    │
    ▼
降采样 + 颜色空间转换（RGB → LAB）
    │
    ▼
提取颜色统计特征
  - L/a/b 各通道均值 μ、标准差 σ
  - 各通道直方图（256 bins）
  - 可选：联合颜色分布（3D histogram）
    │
    ▼
构建颜色映射函数 f: RGB → RGB
  - 基础：Reinhard mean/std 对齐
  - 增强：直方图匹配（CDF 对齐）
  - 混合：intensity 参数控制融合比例
    │
    ▼
在 33×33×33 网格上采样 f
    │
    ▼
输出标准 .CUBE 文件
```

**算法细节：**

对于每个像素，先 RGB→LAB，在 LAB 空间做统计对齐：

```
L_out = (L_src - μ_L_src) * (σ_L_ref / σ_L_src) + μ_L_ref
a_out = (a_src - μ_a_src) * (σ_a_ref / σ_a_src) + μ_a_ref
b_out = (b_src - μ_b_src) * (σ_b_ref / σ_b_src) + μ_b_ref
```

然后用直方图匹配做精细调整，最后通过 `intensity` 参数混合原始和映射后的颜色。

在 33³ 网格上均匀采样 RGB 值 [0, 255]，对每一点执行上述映射，得到 LUT 的三线性插值表。

### 3.2 阶段 2：神经网络 LUT 生成器（后端 Python）

```
电影截图
    │
    ▼
PyTorch 编码器（EfficientNet-B0 或自研轻量网络）
    │
    ▼
提取风格参数 r_s（256 floats）
    │
    ▼
在 33³ RGB 网格上运行 sDNCM
    │
    ▼
输出 .CUBE 文件
```

后端提供 REST API：
- `POST /api/extract-style` — 上传截图，返回风格参数
- `POST /api/generate-lut` — 提供风格参数，生成 LUT
- `POST /api/apply-lut` — 上传照片 + LUT，返回处理结果

## 4. 数据流

### 阶段 1 数据流

```
用户上传截图
  │
  ▼
前端 JS：Image → Canvas → ImageData
  │
  ▼
颜色分析模块（纯 JS，<50ms）
  │
  ▼
LUT 生成模块（纯 JS，<100ms）
  │
  ▼
输出 .CUBE 文件（下载）
  │
  ▼
用户上传自己的照片
  │
  ▼
前端 JS 加载 LUT + 三线性插值应用
  │
  ▼
实时预览结果
```

### 阶段 2 数据流

```
用户上传截图
  │
  ▼
前端 → POST /api/extract-style（截图）
  │
  ▼
后端 GPU 推理（~20ms）→ 返回 r_s（256 floats）
  │
  ▼
前端缓存 r_s，本地生成 LUT（<100ms）
  │
  ▼
输出 .CUBE 文件
  │
  ▼
用户上传照片 → 前端应用 LUT → 实时预览
```

## 6. LUT 格式规范

采用 Adobe 标准 `.CUBE` 格式：

```
# Generated by Color Muse
LUT_3D_SIZE 33

# Domain: [0.0, 1.0] for each channel
0.000000 0.000000 0.000000
0.031250 0.000000 0.000000
...
1.000000 1.000000 1.000000
```

- 33×33×33 = 35937 个 RGB 三元组
- 每个值归一化到 [0.0, 1.0]
- 文件大小约 1.2MB（纯文本）或更小（压缩后）

## 8. 性能预算

| 操作 | 阶段 1（纯前端） | 阶段 2（有后端） |
|------|------------------|------------------|
| 颜色分析 | <50ms | N/A |
| LUT 生成 | <100ms | <120ms（含网络） |
| LUT 应用到 1080p 图 | <200ms | <200ms |
| 端到端（截图→预览） | <500ms | <500ms |

## 9. 错误处理

| 场景 | 处理 |
|------|------|
| 截图颜色过于单一（σ≈0） | 显示警告，建议更换截图 |
| 截图与照片色域差异过大 | 提示可能效果不佳 |
| 浏览器不支持 | 降级到纯 JS 实现 |
| 后端服务不可用（阶段 2） | 自动降级到阶段 1 |
